# 裝備顯示系統

目前流程固定為三層，避免繪製層自行猜測主副手關係：

1. `Profiles`：將物品標成腰部、肩扛、背部、拖地、雙手或盾背。
2. `Layouts`：同時讀取主手與副手，解決唯一位置衝突後產生繪製清單。
3. `Drawing`：只畫布局器已決定的被動清單與手持清單。

`CombatEquipmentTracker` 會保留最後一把有效戰鬥武器，因此玩家暫時拿藥水或非支援物品時，不會讓主副手的既定布局跳到另一把武器。

要為特定武器覆寫自動判斷時，在載入階段呼叫：

`WeaponProfileRegistry.Register(物品類型, WeaponCarryStyle.姿勢, 是否可拖地後備);`

目前已明確處理的衝突：雙手武器優先、肩扛加肩扛改為副手拖地、同類腰部／背部／盾背只留主手。交叉背掛尚未啟用，必須等專用位置與旋轉規格確認後再加入，避免大型武器重疊。

此模組將以一份「主手與副手的整合顯示方案」重新實作。目前各檔案只建立職責骨架，尚未包含功能程式碼。

流程：

1. `Offhand` 管理副手欄位與副手使用期間的狀態。
2. `State` 提供目前主手／副手的裝備快照。
3. `Classification` 判斷每件物品的視覺分類。
4. `Pairing` 一次解析兩件物品，避免它們佔用相同位置。
5. `Poses` 保存解析後的姿勢資料。
6. `Drawing` 繪製已完成解析的顯示方案。
