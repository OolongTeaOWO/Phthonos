# Phthonos

[繁體中文](README.md) · **简体中文** · [English](README.en.md)

> **以你的方式，成就你的传奇。**

Phthonos 是一个开发中的《泰拉瑞亚》大型内容模组，以打造超大型冒险体验为长期目标。它将以重视观察与时机的战斗，以及多样的武器、装备与流派搭配，让玩家在挑战中找到自己的道路。

## 看懂攻势，把握时机

观察敌人的动作，辨识攻势，在进攻、闪避与防御之间作出判断。掌握出手的时机、把握敌人的破绽，让每一次交战都成为理解对手、磨练自身技巧的过程。

## 自由搭配，形成自己的流派

依照自己的习惯与想法搭配武器和装备，探索不同组合的可能性。各种搭配将有自己的优势、限制与操作节奏，让你能用不同方式应对同一场挑战，逐步形成属于自己的战斗风格。

## 合理的规则，有意义的选择

Phthonos 以“合理的自由度”为设计核心。选择伴随取舍，力量伴随代价；理解规则、善用搭配与掌握操作，将成为你克服挑战的依据。

## 开发状态

Phthonos 目前仍处于开发与设计阶段。以上内容为设计方向，不代表所有功能均已完成；具体内容将随版本逐步实现。

目前项目正在实现与调整的内容包括：

- 玩家动作：翻滚与蹲下。
- 主手与副手武器操作。
- 装备展示、备战姿势与武器摆放。
- 翻滚耐力消耗、自然恢复与耐力 HUD。

这些系统仍在测试与调整中，数值、规则及呈现方式都可能变动。

## 开发环境

本项目使用 C# 与 tModLoader。从源代码测试时，请将项目放入 tModLoader 的 `ModSources/Phthonos` 文件夹，再通过游戏内的模组源代码界面构建并重新加载。

目前耐力 HUD 支持原版水平条资源样式；测试时请在设置中选择水平条。
