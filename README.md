# Phthonos

**繁體中文** · [简体中文](README.zh-CN.md) · [English](README.en.md)

> **以你的方式，成就你的傳奇。**

Phthonos 是一個開發中的《泰拉瑞亞》大型內容模組，以打造超大型冒險體驗為長期目標。它將以重視觀察與時機的戰鬥，以及多樣的武器、裝備與流派搭配，讓玩家在挑戰中找到自己的道路。

## 看懂攻勢，把握時機

觀察敵人的動作，辨識攻勢，在進攻、閃避與防禦之間作出判斷。掌握出手的時機、把握敵人的破綻，讓每一次交戰都成為理解對手、磨練自身技巧的過程。

## 自由搭配，形成自己的流派

依照自己的習慣與想法搭配武器和裝備，探索不同組合的可能性。各種搭配將有自己的優勢、限制與操作節奏，讓你能用不同方式應對同一場挑戰，逐步形成屬於自己的戰鬥風格。

## 合理的規則，有意義的選擇

Phthonos 以「合理的自由度」為設計核心。選擇伴隨取捨，力量伴隨代價；理解規則、善用搭配與掌握操作，將成為你克服挑戰的依據。

## 開發狀態

Phthonos 目前仍處於開發與設計階段。以上內容為設計方向，不代表所有功能皆已完成；具體內容將隨版本逐步實現。

目前專案正在實作與調整的內容包括：

- 玩家動作：翻滾與蹲下。
- 主手與副手武器操作。
- 裝備展示、備戰姿勢與武器擺放。
- 翻滾耐力消耗、自然恢復與耐力 HUD。

這些系統仍在測試與調整中，數值、規則及呈現方式都可能變動。

## 開發環境

本專案使用 C# 與 tModLoader。從原始碼測試時，請將專案放入 tModLoader 的 `ModSources/Phthonos` 資料夾，再透過遊戲內的模組原始碼介面建置並重新載入。

目前耐力 HUD 支援原版水平條資源樣式；測試時請在設定中選擇水平條。
